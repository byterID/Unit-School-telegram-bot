# 🎓 Telegram-бот частной школы

Расписание, меню столовой, контакты преподавателей и объявления в одном боте.

## Возможности

| Раздел | Что умеет |
|---|---|
| 📅 Расписание | на сегодня/завтра/неделю, по группе и по преподавателю |
| 🍽 Столовая | меню на день и неделю; администратор добавляет/удаляет блюда |
| 📞 Контакты | ФИО, предмет, телефон (кликабельный), кабинет |
| 📢 Объявления | администратор создаёт → рассылка всем подписчикам |
| ❓ FAQ | частые вопросы с ответами |
| ⚙️ Настройки | своя группа/роль, отключение уведомлений |

## Установка

```bash
git clone <ваш-репозиторий> && cd telegram_bot

python3.14 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate

pip install -r requirements.txt
cp .env.example .env               # Windows: copy .env.example .env
